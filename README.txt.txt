GREEN MINDS

Team Name:
Agri Innovator

Project:
Green Minds

Tagline:
AI-powered agricultural assistant for Indian farmers

ABOUT:
Green Minds is an AI-powered agricultural assistant that provides
simple farming guidance based on crop, soil, weather, and location details.

FEATURES:
- AI-powered farming guidance
- Crop and soil-based advice
- Weather-based suggestions
- Location-based support
- Simple farmer-friendly interface

TECHNOLOGIES:
- HTML
- CSS
- JavaScript
- Python
- Flask
- Gemini AI

HOW TO USE:
1. Open the Green Minds website.
2. Enter the farmer and farming details.
3. Click "Get AI Advice".
4. View the AI-generated farming guidance.

PROJECT GOAL:
To provide simple and accessible AI-powered farming guidance
for Indian farmers.

PROJECT STATUS:
Working prototype for hackathon demonstration.
